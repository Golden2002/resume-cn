# 中文写作审校

一份可以独立拿用的中文写作规则集。规则全部可机器判定，出处写在条号里，不靠“我觉得”。

## 何时用

- 写中文简历、求职邮件、个人陈述
- 写项目说明、设计文档、决策记录
- 写教学材料、讲义、评估说明
- 修改任何有“翻译腔”“机器味”的中文

## 四条依据

| 出处 | 管什么 |
|---|---|
| GB/T 15834—2011《标点符号用法》 | 全角标点、破折号、引号、连接号 |
| GB/T 15835—2011《出版物上数字用法》 | 数字与量词、数字与单位之间的空格与写法 |
| W3C《中文排版需求》clreq | 中西文混排的空格、标点挤压、行首行尾禁则 |
| 余光中《中文的常态与变态》 | 拆散单音节动词、虚指主语、赘余、长定语前饰、被动滥用 |

余下几条属于行文习惯，来自对 AI 生成文本的观察，单列在最后一节。

## 正例反例

反例（三类毛病挤在一句里）：

```
我进行了为期四天的课程设计，这让我意识到教育的本质，此外人们也普遍认为
教学至关重要。
```

改后：

```
我独立设计了为期四天的课程。学员在第三天能自己提出可检验的问题，这是我
判断课程是否有效的依据。
```

改动点：

1. 删掉 `进行了`，换成具体动词 `设计`。
2. 删掉伪发现 `这让我意识到` 与空心评价 `至关重要`。
3. 把评价换成可核对的证据：学员能提出可检验的问题。
4. 删掉 `人们也普遍认为` 这类无主体的归因。

## 审校流程

1. **先看主语。** 每个句子的主语是不是具体的人或物。抽象名词作主语就改。
2. **数从句。** 一句里叠三个以上从句就拆。
3. **删虚字。** `的`、`地`、`以及`、`进行`、`作出`，见一个删一个。
4. **查标点。** 全角标点、弯引号、破折号不加空格。
5. **查空格。** 中文与西文、数字与量词之间留半角空格。
6. **朗读。** 拗口处就是病处。
7. **过机器。** 能自动判的交给脚本，别靠自我评价。

## 与代码的配合

本规则集的 17 条已实现在 [resume-cn](../../README.md) 的语言门禁里，可对任意文本执行一遍：

```bash
node -e "const g=require('./src/gates/language');console.log(g.check(require('fs').readFileSync(0,'utf8')))"
```

判定是确定性的，不含模型判断，因此可以挂进 CI 当门禁用。交付前要求 0 违例。
